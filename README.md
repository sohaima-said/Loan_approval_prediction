# Loan_approval_prediction
This project builds a machine learning model that predicts whether a loan application will be approved or rejected, using the applicant’s personal, financial and loan details. It uses the Kaggle Loan Prediction dataset of 614 applications. After filling in missing values and creating new features, the data is split 80/20 and scaled. Three algorithms are then trained and compared: Decision Tree, Naive Bayes and KNN. They are evaluated with accuracy, precision, recall, F1-score and confusion matrices. Naive Bayes performed best with 84.55% accuracy, and credit history turned out to be the strongest factor in deciding approval.
